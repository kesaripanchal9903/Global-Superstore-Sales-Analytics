# SQL Analysis

This folder contains SQL queries developed to analyse the Global Superstore dataset using MySQL.

## Analysis Areas

- Data exploration and validation
- Sales and profit analysis
- Category and sub-category performance
- Regional performance
- Customer and segment analysis
- Discount and profitability analysis
- Shipping and operational analysis
- Year-over-year and month-over-month growth
- Advanced SQL using CTEs, Window Functions, and CASE statements

## Database
- Database: MySQL
- Table: orders
