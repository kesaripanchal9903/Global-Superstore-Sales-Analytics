# SQL Analysis

This folder contains SQL queries developed to analyse the Global Superstore dataset using MySQL.

## Analysis Areas

- Data exploration and validation
- Sales and profit analysis
- Category and sub-category performance
- Regional performance
- Customer and segment analysis
- Discount and profitability analysis
- Shipping and operational analysis
- Year-over-year and month-over-month growth
- Advanced SQL using CTEs, Window Functions, and CASE statements

## Database
- Database: MySQL
- Table: orders


## SQL Scripts

The SQL analysis is organised into five scripts covering data exploration, sales performance, profitability, customer behaviour, and advanced SQL techniques.

| Script | Description |
|---|---|
| [01_Data_Exploration.sql](01_Data_Exploration.sql) | Initial data exploration and business-level metrics |
| [02_Sales_Analysis.sql](02_Sales_Analysis.sql) | Regional, category, monthly, and product sales analysis |
| [03_Profitability_Analysis.sql](03_Profitability_Analysis.sql) | Loss-making products, discount impact, and profit margins |
| [04_Customer_Analysis.sql](04_Customer_Analysis.sql) | Customer segments, purchase behaviour, and profitability |
| [05_Advanced_SQL_Analysis.sql](05_Advanced_SQL_Analysis.sql) | CTEs, window functions, rankings, cumulative sales, and growth analysis |

**SQL Concepts Used:**
- Joins and aggregate functions
- GROUP BY and HAVING
- Common Table Expressions (CTEs)
- CASE statements
- Window functions (LAG, RANK, ROW_NUMBER)
- Running totals and cumulative analysis
- Year-over-Year (YoY) and Month-over-Month (MoM) growth
