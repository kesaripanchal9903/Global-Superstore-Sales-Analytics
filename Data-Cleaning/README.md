# Data Cleaning

This folder documents the data-cleaning and preparation process performed before SQL analysis.

## Tools Used
- Microsoft Excel
- Python
- Pandas
- Jupyter Notebook

## Cleaning Activities
- Checked duplicate records.
- Identified missing values.
- Validated date fields.
- Checked negative Sales and Quantity values.
- Removed an unnecessary non-English column.
- Standardised the dataset for MySQL import.

## Final Dataset
- Total Records: 51,290
- Total Columns: 26
